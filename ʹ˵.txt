OC档案馆第一版使用说明

1. 双击 index.html 即可在浏览器中查看网站。
2. 网站文字主要在 index.html 中修改，可使用记事本或 Visual Studio Code 打开。
3. 人物、故事和世界观中标有“待填写”“待替换”的内容都是示例占位内容。
4. 更换约稿图片时：
   - 把图片放进本文件夹中新建的 images 文件夹；
   - 将对应的 <div class="art ..."> 改成 <img src="images/图片名.jpg" alt="作品说明">；
   - 请保留或补充画师署名。
5. styles.css 控制颜色、排版和手机适配；script.js 控制筛选、人物弹窗和移动端菜单。
6. 以后可以免费发布到 GitHub Pages、Cloudflare Pages 或 Netlify。

为了继续替换成你的正式网站，请准备：
- 网站名称和一句简介
- 世界观说明
- 每个人物的名字、身份、简介和立绘
- 主线及支线标题、简介、正文
- 约稿图片与画师署名

【作者后台】
网站发布到 GitHub 后，打开 https://app.pagescms.org/ 并进入
Deerdier/weather-forecast-story，即可看到“网站内容管理”。
这里可以用中文表单新增或修改：人物档案、支线故事、约稿与画廊。
点击保存后，Pages CMS 会把内容直接保存到 GitHub，通常稍等一两分钟网站就会更新。

注意：.pages.yml 和 content/site.json 是后台需要的文件，请不要删除。
现有 16 章主线仍保存在 story.html，不会被后台修改。
